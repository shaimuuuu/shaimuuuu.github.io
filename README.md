# Mohammed Saheem MA — Portfolio

Multi-page static site: Home, Resume, Bio-data, Projects, Contact. Plain HTML, CSS and jQuery, no build step.

## Publish on GitHub Pages

1. Create a public repository named `<your-username>.github.io` (this gives the URL `https://<your-username>.github.io`), or any name such as `portfolio` (URL `https://<your-username>.github.io/portfolio/`).
2. Upload everything in this folder to the repository root (`index.html` must be at the top level).
3. Repository **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**.
4. Wait about a minute, then open the URL shown on that page.

## Before you publish

Open `biodata.html` and replace the rows marked "Add before publishing" (date of birth, father's name, nationality, address) or delete them. Add a LinkedIn link in `contact.html` if you want one.
